# hello-world

Dette prosjektet inneholder en tidlig prototype av et Pokémon-spill for nettleseren skrevet i HTML, CSS og JavaScript. Spillet er på norsk og lar deg gå rundt i gresset og kjempe mot ville Pokémon.

## Starte spillet

1. Åpne `index.html` i en nettleser.
2. Bruk piltastene for å bevege spillfiguren.
3. Når en vill Pokémon dukker opp, velg angrep fra menyen.

Dette er kun en enkel demonstrasjon og ikke en fullstendig kopi av Fire Red.
